# 🎨 Mood Palette Generator

**Type how you feel. Get a color palette that matches.**

Mood Palette Generator turns a mood, feeling, or short line of text into a custom 5-color palette — complete with a mood-matched message, emoji, and (in the web app) an animated, mood-reactive background.

Type something like *"I feel calm and dreamy today"* or *"planning my best friend's wedding"*, and it detects the sentiment and context behind your words to hand you a palette that fits.

---

## ✨ Features

- 🧠 **Sentiment-aware mood detection** — uses NLTK's VADER sentiment analyzer to classify text as `happy`, `sad`, or `calm`.
- 🔑 **Keyword-based theme detection** — recognizes context like *birthday*, *wedding*, *party*, *romantic*, *study/focus*, *aesthetic*, *dark*, and *light*, then blends it with sentiment to produce combined moods like `happy_birthday`, `sad_wedding`, `excited`, or `disappointed`.
- 🎨 **Dynamic HSV-based palette generation** — procedurally builds 5-color palettes by varying hue, saturation, and brightness around each mood's base tone, so every run feels fresh.
- 💎 **Curated palette sets** — hand-picked color combinations for standout moods like `happy_birthday`, `happy_wedding`, `excited`, and `romantic`.
- 💬 **Mood-matched messages** — every detected mood comes with a short emoji + caption (e.g. 🎂 *"Celebration mode!"*).
- 🖥️ **Two ways to use it:**
  - `main.py` — a CLI version that prints your palette and renders it with Matplotlib, saving the result as `generated_palette.png`.
  - `app2.py` — an interactive **Streamlit** web app with animated, mood-reactive gradient backgrounds and hoverable color swatches.

## 🚀 Usage

### Option 1 — Command-line version

```bash
python main.py
```

You'll be prompted to enter your mood or a short piece of text. The script will:
1. Detect your mood/theme
2. Generate a 5-color palette
3. Print the hex codes and a mood-matched message
4. Display and save the palette as `generated_palette.png`

### Option 2 — Streamlit web app

```bash
streamlit run app2.py
```

Type your mood into the text box, hit **Generate Palette**, and watch the background animate to match your vibe while your custom color swatches appear below.

---

## 🎯 How It Works

1. **Preprocessing** — input text is lowercased and cleaned of extra whitespace.
2. **Mood detection** — VADER scores the text's sentiment (`happy`, `sad`, or `calm`), then keyword matching layers in a theme (`birthday`, `wedding`, `party`, etc.) to produce a combined mood label like `happy_wedding` or `excited`.
3. **Palette generation** — for moods with curated sets, a palette is chosen at random from hand-picked options; otherwise, one is generated by varying hue, saturation, and brightness around the mood's base HSV color.
4. **Presentation** — the palette is shown with an emoji, a short caption, and hex codes — either as a Matplotlib figure (CLI) or animated Streamlit swatches (web app).
